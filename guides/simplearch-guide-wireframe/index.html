Bootloader

Choosing between GRUB and Limine, and configuring Plymouth + UKI options.

GRUB vs Limine

By default, archinstall pre-selects systemd-boot, but for a resilient daily driver, you want a bootloader that natively connects to Btrfs snapshot rollbacks. Both GRUB and Limine support this, but Limine provides the cleanest integration with limine-snapper-sync, perfectly replicating Omarchy's instant boot-menu rollback pattern.

Recommended: Limine (or GRUB)

Plymouth: Details Mode

Plymouth renders a splash graphic during boot. For your first Arch installation, enable it and choose the details theme. This displays kernel text through Plymouth's renderer so you have instant visibility if anything hangs during early boot. Once your setup is verified, you can swap to an aesthetic graphical theme with a single pacman command.

Legacy Hardware Tip If installing on ancient graphics (e.g. Intel GMA or Pentium E5800), keep Plymouth disabled to prevent blank-screen driver hangs.

Keep Unified Kernel Image (UKI) disabled for now

A Unified Kernel Image bundles the kernel, initramfs, and cmdline into a single signed EFI executable. While great for Secure Boot, Limine requires separate kernel and initramfs files to dynamically inject rootflags=subvol=<snapshot> for Btrfs snapshot rollbacks. Enabling UKI here breaks automatic boot-menu snapshot rollback.
